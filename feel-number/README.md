# rheon-feel-number

[![crates.io](https://img.shields.io/crates/v/rheon-feel-number.svg)](https://crates.io/crates/rheon-feel-number)
[![docs.rs](https://docs.rs/rheon-feel-number/badge.svg)](https://docs.rs/rheon-feel-number)
[![license](https://img.shields.io/badge/License-MIT%20OR%20Apache--2.0-9370DB.svg)](https://github.com/spearsandshields/rheon#license)

The FEEL number type (exact 34-digit decimal arithmetic in pure Rust) of [rheon](https://github.com/spearsandshields/rheon), a Rust decision and process
stack in the making. This crate is a permanent fork of
[`dsntk-feel-number`](https://crates.io/crates/dsntk-feel-number) from
[DecisionToolkit](https://github.com/DecisionToolkit) by Dariusz Depta; every change against
upstream is listed in
[docs/FORK.md](https://github.com/spearsandshields/rheon/blob/main/docs/FORK.md).
