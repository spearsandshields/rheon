# rheon-model-evaluator

[![crates.io](https://img.shields.io/crates/v/rheon-model-evaluator.svg)](https://crates.io/crates/rheon-model-evaluator)
[![docs.rs](https://docs.rs/rheon-model-evaluator/badge.svg)](https://docs.rs/rheon-model-evaluator)
[![license](https://img.shields.io/badge/License-MIT%20OR%20Apache--2.0-9370DB.svg)](https://github.com/spearsandshields/rheon#license)

The DMN model evaluator of [rheon](https://github.com/spearsandshields/rheon), a Rust decision and process
stack in the making. This crate is a permanent fork of
[`dsntk-model-evaluator`](https://crates.io/crates/dsntk-model-evaluator) from
[DecisionToolkit](https://github.com/DecisionToolkit) by Dariusz Depta; every change against
upstream is listed in
[docs/FORK.md](https://github.com/spearsandshields/rheon/blob/main/docs/FORK.md).
